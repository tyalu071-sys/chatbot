How to Run Yalini GPT

1. Install Python.

2. Install Ollama.

3. Download the model:
   
   "ollama pull llama3.2:1b"

4. Install the Python package:
   
   "python -m pip install ollama"

5. Run the chatbot:
   
   "python yalini_gpt.py"
